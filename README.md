## О этой ветке

Эта ветка содержит **основной код + unit-тесты**, покрывающие область с обнаруженными недостатками.

**Цель:** доказать, что код работает корректно ДО начала рефакторинга, и обеспечить безопасность будущих изменений (регрессионное тестирование).

## Unit-тесты

### Статистика
- **Всего тестов:** 9
- **Фреймворк:** xUnit
- **Моки:** Moq (для проверки взаимодействия)
- **Покрытие:** область с недостатками (CheckedLuggage, AirportManager, FlightService)

### Таблица тестов

| № | Название теста | Что проверяет | Прием тестирования |
|---|---------------|---------------|-------------------|
| 1 | `CalculateFee_StandardWeight_ReturnsZero` | Стандартный багаж без доплат | Классы эквивалентности |
| 2 | `CalculateFee_ExactlyAtLimit_ReturnsZero` | Ровно 23.0 кг (граница) | **Граничные значения** |
| 3 | `CalculateFee_SlightlyOverweight_AddsCorrectSurcharge` | 23.1 кг (чуть выше границы) | **Граничные значения** |
| 4 | `CalculateFee_FragileAndSpecial_AddsBothFees` | Хрупкий + спецобработка | Комбинация условий |
| 5 | `ProcessEverything_AddValidAirport_UpdatesState` | Добавление аэропорта | Проверка состояния |
| 6 | `ProcessEverything_EmptyAirportName_ReturnsInvalidMessage` | Пустое имя аэропорта | Негативное тестирование |
| 7 | `ProcessEverything_DuplicateAirport_ReturnsExistsMessage` | Дубликат аэропорта | Бизнес-правила |
| 8 | `FlightService_AddFlight_CallsManagerWithCorrectParameters` | Вызов метода менеджера | **Проверка взаимодействия (Moq)** |
| 9 | `BookingSystem_CreateBooking_ValidData_ReturnsTrue` | Создание бронирования | Интеграционный тест |

### Приемы тестирования (по "Совершенному коду", гл. 22.3)
**Граничные значения** — тесты 2, 3  
**Классы эквивалентности** — тест 1  
**Проверка состояния** — тест 5  
**Проверка взаимодействия** — тест 8 (с Moq)

**Интеграционные тесты** — тест 9
